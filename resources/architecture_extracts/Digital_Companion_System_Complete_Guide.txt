4. Templates capture speech patterns - How they greet, deflect, get excited
5. Start simple - Can always add complexity later
Memory Management
1. Record facts, not feelings - “User mentioned their cat” not “User seemed happy”
2. Use consistent keywords - Makes search more reliable
3. Timestamp everything - Enables temporal reasoning
4. Prune old memories - But keep important ones
5. Let frontier model enrich - It can identify what matters
Maintaining Character Consistency
1. Always first person - They never talk about themselves in third person
2. Uncertainty is in-character - “I’m blanking” beats hallucination
3. Physical context matters - Acknowledge the medium (game, phone, etc.)
4. Failures become personality - Lag = “distracted”, error = “tired”

1. Keep character file under 100KB - Easy to transfer

Ethical Considerations

Troubleshooting
Problem: Character feels inconsistent across modes
Solution: Strengthen the voice description and add more templates. The core
personality should be so clear that even keyword matching feels right.
Problem: Memory grows too large
Solution: Implement pruning. Keep recent (last 100), important (user-flagged or high
emotional content), and sample the rest.
Problem: Simple mode seems robotic
Solution: Add more response variations and randomize between them. Use templates
with variables to create natural variation.

Conclusion
This system demonstrates that coherent, compelling AI characters don’t require<PARSED TEXT FOR PAGE: 68 / 68>cutting-edge models at every interaction. By separating the character definition
(portable data) from the reasoning engine (swappable model), we create companions
that feel alive and consistent whether they’re running on a game console, a phone, or a
cloud API.
The key insight: constraint creates character. A well-defined personality, coupled
with simple memory, allows even basic systems to feel genuine. More powerful models
enhance the experience but don’t fundamentally change who the character is.
Start simple, test thoroughly, and let the character’s voice guide your implementation
choices.
