# Identity corpus

This directory is the versioned source boundary for the comprehensive reconstruction.

Do not fabricate missing canon. Import existing Pretorius material here only after its origin is known.

The intended source classes are canonical character history, prior Pretorius project history, LoRA metadata and training provenance, voice examples, relationship evidence, preferences and aversions, important decisions, and known contradictions.

Raw copyrighted source text does not need to be committed. Prefer source references, structured summaries, hashes, and derived annotations when appropriate.

Use `IMPORT_MANIFEST.example.json` as the schema for tracking incoming material. The mutable memories Agent Pretorius forms after activation belong in the runtime SQLite database, not in this directory.
