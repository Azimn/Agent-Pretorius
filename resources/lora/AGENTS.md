# LoRA corpus context

This directory preserves the Pretorius training-data lineage.

Treat these records as evidence about desired mature phenotype, voice, scenario coverage, and how the reconstruction changed across versions. They are not automatically canonical biography.

When comparing versions, preserve provenance and identify additions, removals, voice corrections, and changed behavioral assumptions. Do not silently collapse the lineage into the newest file.

Actual trained adapter weights and adapter configuration were not located during archive consolidation. Dataset presence therefore does not imply that a LoRA adapter is currently loaded by Hermes.
